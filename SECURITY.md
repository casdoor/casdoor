# Security Policy

## Reporting a Vulnerability

We are grateful for security researchers and users reporting a vulnerability to us first. To ensure that your request is handled in a timely manner and we can keep users safe, please follow the below guidelines.

- **Please do not report security vulnerabilities directly on GitHub.**

- To report a vulnerability, please email [admin@casdoor.org](mailto:admin@casdoor.org).

- A useful report includes the affected version or commit hash, a clear description of the security impact, and concrete steps or a proof of concept to reproduce the issue. Please confirm the issue against the latest `master` before reporting.

## IMPORTANT

We do not accept AI-generated security reports. We receive a large number of these, and we absolutely do not have the resources to review them all. If you submit one, that will be an automatic ban from the project.

The same applies to using AI tools to run automated vulnerability scans, fuzzing, or penetration testing against this project or any of its hosted instances, including our demo and production sites. This kind of automated probing floods us with low-quality, false-positive reports that we cannot review, and running it against our live services degrades them for real users, wastes our resources, and amounts to an unauthorized attack rather than responsible research. Anyone doing this will be banned from the project.
